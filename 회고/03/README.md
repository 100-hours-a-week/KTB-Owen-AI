3주차 회고

- 각 파트에 대해 대충 문법보고 써보고 넘어가는게 아니라, 깊이있는 동작원리부터 각각 개발자의 철학, 내부구조를 다 뜯어보면서 처음으로 완전히 깊이 공부했다. 그래서 절대적 시간이 부족했고, 그것이 여전히 시각화 파트까지 공부하지 못한 이유 같다. 하지만 이 파트의 중요성을 알고있기 때문에 이번 과제를 못했다는 아쉬움이 있지만 이번 파트만큼은 그보다 더 깊게 공부했다는 것이 중요하다 생각하였다. 그래서 다음주 진도에 추가로 데이터 시각화 부분을 깊게 공부를 병행하고, 남은 과제를 마무리 해두겠다. 
- 데이터 시각화 부분은 못했는데, 이 파트는 다음주에 틈틈히 공부해서 과제 마무리 꼭 해두겠다
